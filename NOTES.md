# Working notes — Daewon Kim 3D CV

Handoff for future sessions: current state + the hard-won principles/gotchas of
this codebase. Read this first. (The vox model pipeline has its own guide:
`lib/three/styles/vox/README.md`.)

## What this is

Interactive pixel-art **3D CV** for Daewon Kim. **Next.js 15.5 (App Router) +
vanilla Three.js r172 (NOT react-three-fiber)**. Single page. Fixed dimetric
orthographic camera, `RenderPixelatedPass` pipeline, a floating voxel island with
8 CV landmarks. Dev: `npm run dev` → http://localhost:3000. `?h=<hour>` forces
the time of day (e.g. `?h=18.5`).

**Deploy:** push to `main` → Vercel auto-deploys two projects from this repo:
`3dcv-2` → https://daewonkimcv.vercel.app (main) and `3dcv` →
https://3dcv-sigma.vercel.app. `npx vercel ls <project>` (CLI is logged in as
vinyl810) shows status. Run `npm run build` before pushing (stop the dev server
first — both use `.next/`).

## Architecture

```
app/page.tsx (server, ISR 60s) ─ getMarks() ─► components/Experience (client state)
  ├ SceneCanvas ─ dynamic import ─► lib/three/engine.ts (DioramaApp)
  │                                  └ models.ts buildWorld(scene, style, marks)
  │                                     ├ environment.ts  sky shader, lights, TOD, visitor fireflies
  │                                     └ styles/vox      island + ocean + 8 landmarks (.vox)
  ├ Overlay (title, tooltip, panel/popup, dot-nav)   └ TraceBox (guestbook) ─► app/actions.ts ─► lib/marks.ts ─► Neon
```

- **`lib/three/layout.ts`** — single source of landmark slots (id, label, pos,
  scale, keepOut), `GRASS_TOP = 0.5`. `station.id` in `lib/cv-data.ts` must match.
  (`lib/marks.ts` still has its own `KEEPOUT` copy — server-only module; keep in sync.)
- **`lib/three/styles/`** — `StyleSet` contract (`types.ts`): `landmarks`,
  `buildIsland`, `buildOcean`, optional async `preload`. Only **`vox`** ships;
  `index.ts` `loadStyle()` returns it. The contract stays so a future look can be
  swapped in one place. (Experimental classic/voxel/kit/refined styles were
  removed 2026-11-02; they're in git history before that date.)
- **`styles/vox`** — MagicaVoxel `.vox` models generated by Node scripts in
  `tools/` → `public/models/vox/` (+ `manifest.json`), parsed + greedy-meshed at
  runtime. Rebuild: `node lib/three/styles/vox/tools/build.mjs [names…]`
  (**regenerating overwrites hand edits** — see its README).
  - One on-screen voxel size: `VOXEL = 0.125`; landmarks compensate for their
    root scale (`slot.scale × PROP_SCALE 1.35`). Characters use `CHAR_RES = 2`
    (0.0625) — finer grain, deliberately simple shapes.
  - Painted per-voxel shading + AO (`tools/paint.mjs`, `ao: 0.22`) on everything
    — flat single-colour regions read as low-res next to the painted island.
  - Characters (hub Daewon + 3 involvement people) are stylized (head ≈ 1/3,
    dot eyes, blush; NOT realistic — semi-realistic faces read as uncanny here),
    one skinned mesh each with a 15-joint rig (`rig.ts`): hips→torso→head,
    shoulder→elbow→wrist, hip→knee→ankle; rounded joint caps so bends never gap.
- **`environment.ts`** — `TOD_KEYS` keyframes (eased) → sky shader, key/ambient/
  hemi/rim lights, shadow intensity, `star` (night factor). Sky is a SCREEN-SPACE
  gradient (the camera looks down, so a world-space dome only ever showed one
  colour) with 4×4 Bayer dither, clouds, horizon glow, moon + stars drawn in the
  shader (meshes got outlined by the edge pass). Moon placed in CSS px away from
  the top-left title. Night lights: any `PointLight` with `userData.nightBase`
  gets `nightBase × s.star` (models.ts).

## Principles / gotchas (learned the hard way here)

1. **Facing:** camera looks from **+X+Y+Z**. Models face `+Z` then the group gets
   **`rotation.y = Math.PI / 4`**.
2. **Never scale absolute time by hover.** `osc(t * (1 + hover))` jumps the phase.
   Hover may change emissive/amplitude/lift only. Click bursts use
   `makeSelectionClock()` (seconds since the click), never scaled `t`.
3. **Hover/click raycast STABLE proxies** (oriented boxes from each model's rest
   bounds, on **layer 1**, siblings of the animated root) — auto-computed in
   `models.ts`, so a model's bounding box IS its hit area. Knobs `PROXY_*`.
4. **Shared cached materials** (`mat/emit/glass` in `kit.ts`): clone before
   animating. Shadows: `applyShadowFlags` judges "glowing" by emissive COLOUR
   (toon `emissiveIntensity` defaults to 1); opt out with `userData.noShadow`.
5. **Pixel pipeline:** `RenderPixelatedPass` (block ≈ 3.5 CSS px, normal edge
   0.38, depth edge 0.5) → `OutputPass`; AA off; `MeshToonMaterial` + 8-entry
   `GRADIENT` ramp. Detail smaller than one block (e.g. 1-voxel catch-lights at
   0.0625) disappears at default zoom — design for 2–3 voxel features.
6. **Semantics over detail:** every prop must be nameable at default zoom
   ("that's a book"). Check occlusion by neighbours/island lamps, orientation
   (spines/page edges toward camera), and avoid duplicate symbols across
   landmarks. A read-only "semantic audit" with 3.6× close-ups worked well.
7. **Camera zoom/pan** (`engine.ts`): pinch/wheel zoom, 1-finger pan when
   zoomed, select fires on pointer-UP (`TAP_SLOP`). `setPointerCapture` can throw
   → keep the try/catch. Mobile intro zoom `INTRO_*`.
8. **UI font:** self-hosted **NeoDunggeunmo** (`public/fonts`, OFL) for Latin +
   Hangul. It's drawn on a **16px grid** → only 16px / 32px font sizes (others
   blur). Mobile panel heading 16px.
9. **Verification that worked:** headless Playwright screenshots (+ contact
   sheets) at several `?h=` hours, desktop 1440×900 + mobile 390×844, close-up
   frame sequences for animation; read the images — tsc passing ≠ it looks right.

## Visitor guestbook (Neon Postgres)

Visitors plant a glowing firefly (colour + optional ≤24-char label) that
persists for everyone. Neon via `@neondatabase/serverless`; ONE table `marks`,
auto-created. Server-only `lib/marks.ts`; write = Server Action `plantMark`
(rate limit 1/IP/hour, sha256 `ip_hash` + `MARK_SALT`); read = `getMarks()`
cached 60s. No `DATABASE_URL` → "Coming soon" (graceful). Live on Vercel
(env set); locally `.env.local` has `DATABASE_URL`. Own fireflies are tracked in
localStorage (`cv:my-fireflies`) → pin + "find my firefly" ping.

## Known issues (not yet fixed)

1. **Guestbook submit can hang** — no try/catch around `plantMark` in
   `Experience.onPlant` / `TraceBox.submit`; a thrown Server Action leaves the
   button on "Lighting…".
2. **Mark caps disagree** — server `RENDER_CAP` 150 vs client `CAP` 200; client
   evicts by insertion order while initial marks arrive newest-first.
3. **Sticky hover on touch** — `pointerActive` stays true after a tap.
4. **Dispose** skips every `BoxGeometry` (cable geometries never freed); cloned
   materials aren't disposed.
5. `lib/marks.ts` `KEEPOUT` duplicates `layout.ts` (see Architecture).
6. Visuals: dusk grass slightly olive; cloud dither a bit stripy up close; stars
   shift on window resize; involvement banner's hands are hidden by a mentee's
   head (only the heart reads).

## User preferences

- Communicates in **Korean** → respond in Korean.
- Iterates heavily on visual detail; expects **screenshots before claiming
  done**; likes side-by-side comparisons of alternatives (e.g. `?style=`,
  `?char=` switches while exploring) and single tunable knobs.
- Disliked: big chibi heads, boxy characters, semi-realistic (uncanny) faces,
  flat single-colour sky, illegible tiny pixel fonts.
- Mobile = full-screen 3D + zoom + popup (rejected a split layout).
