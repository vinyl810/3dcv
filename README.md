# Daewon Kim — Interactive 3D CV

An interactive, single-page **pixel-art 3D résumé** built with **Next.js** and **Three.js**.

The CV is presented as a floating isometric voxel island — *"Daewon's Drifting
Archipelago"* — viewed through a **fixed orthographic camera**. Eight themed
landmarks fan out around a central hub, each mapping to a section of the CV.
**Hover** a landmark for a label, **click** it to slide open an info panel with the
details. The whole scene is rendered through Three.js's `RenderPixelatedPass` for a
crisp, consistent pixel-art look.

## Highlights

- **Fixed isometric camera** — no orbit; the diorama is composed to read from one angle.
- **Consistent pixel aesthetic** — `EffectComposer → RenderPixelatedPass → OutputPass`,
  a single flat-shaded `MeshToonMaterial` palette, nearest-filter textures, and
  antialiasing disabled so the pixel grid never smears.
- **MagicaVoxel models** — every landmark, character and the island are `.vox`
  files generated by Node scripts (`lib/three/styles/vox/tools/`) and editable in
  MagicaVoxel; rigged, animated characters; a live day-night cycle on Korean time.
- **Single page** — one route; info is revealed through an HTML overlay while the 3D
  scene stays put behind it.
- **Mobile-first** — the orthographic frustum re-fits so the whole island stays visible
  from ultrawide down to portrait phones; taps are forgiving (screen-space nearest-landmark
  assist), the bottom **dot row doubles as a tappable section nav**, the panel goes
  full-screen with momentum scroll, notch/home-indicator safe-areas are respected, and the
  render loop pauses when the tab is backgrounded.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
# production
npm run build && npm start
```

Requires Node 20+.

## How it's wired

See `NOTES.md` (architecture, principles, gotchas) and
`lib/three/styles/vox/README.md` (editing / rebuilding the voxel models).

```
app/            page.tsx (ISR), actions.ts (guestbook), globals.css (pixel font)
components/     Experience, SceneCanvas, Overlay, TraceBox, ui.module.css
lib/cv-data.ts  ALL CV content (8 stations)
lib/marks.ts    guestbook data layer (Neon Postgres, server-only)
lib/three/
  engine.ts       renderer, fixed ortho camera, pixel pass, picking, RAF loop
  models.ts       buildWorld(): places landmarks, hit proxies, night lights
  environment.ts  time-of-day keyframes, sky shader, lights, visitor fireflies
  layout.ts       landmark slots (ids/positions) shared by everything
  kit.ts          palette, toon ramp, material + primitive helpers
  styles/vox/     .vox loader/mesher, rig, island, ocean, 8 landmarks, tools/
public/models/vox .vox assets + manifest.json
```

## Extending it

- **Edit CV content:** `lib/cv-data.ts`. Each `station.id` must match a slot in
  `lib/three/layout.ts`.
- **Edit a model:** change its generator in `lib/three/styles/vox/tools/models/`
  and run `node lib/three/styles/vox/tools/build.mjs <name>` (or edit the `.vox`
  in MagicaVoxel — see that folder's README before regenerating).
- **Tune the look:** time-of-day colours/lights in `lib/three/environment.ts`;
  pixel size, framing and edge strengths in `lib/three/engine.ts`.
